# evaluation

## Purpose
Metrics for virtual-infant runs: convergence of each parameter to its true value, coverage of the stated uncertainty intervals, the identifiability table, and dose quality against the dose that would be optimal given the true parameters.

No files yet.

## Inputs/Outputs
- Inputs: run outputs and the simulator's true parameters.
- Outputs: metrics, written to `results/virtual/`.

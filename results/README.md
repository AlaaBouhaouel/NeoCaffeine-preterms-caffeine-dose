# results

## Purpose
Tracked run outputs. Only virtual-infant outputs belong here; real patient data and outputs derived from it never do.

## Contents
- `virtual/`: virtual-infant run outputs.

## Inputs/Outputs
- Inputs: files written by the runner and the evaluation layer.
- Outputs: committed results for review and comparison.

## Depends on
Nothing.

## Used by
Anyone reviewing virtual-infant runs.
